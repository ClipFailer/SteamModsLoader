# Steam Workshop Batch Downloader & Extractor

Набор скриптов для полностью автоматической пакетной загрузки модов и целых коллекций из мастерской **Steam Workshop** с помощью утилиты **SteamCMD**, а также для их последующего объединения в готовую папку `mods`.

Особенно полезно для **Project Zomboid** и других игр, где моды из Workshop имеют вложенную структуру и требуют ручного ввода команд.

---

## ✨ Возможности

- 🚀 **Загрузка в один клик:** Больше не нужно вручную вводить команды `workshop_download_item <AppID> <ModID>` в консоль SteamCMD.
- 📦 **Поддержка коллекций Steam:** Вставьте одну ссылку на коллекцию из 200+ модов — скрипт сам автоматически найдет и скачает каждый мод из этой коллекции.
- 🔗 **Гибкий формат ввода:** Принимает как прямые ID модов (`3814398576`), так и полные ссылки из браузера (`https://steamcommunity.com/sharedfiles/filedetails/?id=...`).
- 🌐 **Прямая работа со Steam API:** Скрипт напрямую запрашивает официальный Web API Steam (без использования сторонних сайтов), определяя AppID игры, валидность и названия модов.
- 📂 **Автоматический сборщик (Extractor):** Проходится по всем скачанным папкам Workshop, извлекает содержимое их внутренних папок `mods` и собирает их в одну чистую общую папку `mods`, готовую к закидыванию в игру.

---

## 📁 Структура проекта

```text
SteamMods/
├── SteamCMD/
│   └── steamcmd.exe      # Сама утилита SteamCMD (все кэши и скачанные файлы скрыты в .gitignore)
├── download_mods.py      # Скрипт парсинга ссылок/коллекций и запуска скачивания через SteamCMD
├── run.bat               # Запуск загрузки модов двойным кликом
├── extract_mods.py       # Скрипт сборки всех модов в единую папку mods
├── extract.bat           # Запуск сборщика модов двойным кликом
├── mods.txt              # Список ссылок или ID модов для скачивания
├── .gitignore            # Исключает весь мусор и кэши SteamCMD, отслеживая только steamcmd.exe
└── README.md             # Документация проекта
```

## 🚀 Инструкция по использованию

### Шаг 1. Добавление модов
Откройте файл **`mods.txt`** и вставьте нужные ссылки или ID модов (по одной на строку). Можно вставлять ссылки на целые коллекции:

```text
# Ссылка на коллекцию (скрипт распакует все моды из нее):
https://steamcommunity.com/sharedfiles/filedetails/?id=3812839109

# Или ссылка на отдельный мод:
https://steamcommunity.com/sharedfiles/filedetails/?id=3814398576

# Или просто ID мода:
2850935956
```

### Шаг 2. Скачивание модов
Запустите **`run.bat`** (или выполните команду `python download_mods.py`).

1. Скрипт проверит ссылки, определит AppID игры и названия модов.
2. Сформирует команды для SteamCMD и запустит скачивание всех модов подряд за одну сессию.
3. Дождитесь надписи `[+] Загрузка завершена!`.

> 💡 **Куда сохраняются исходники:**
> В стандартную папку SteamCMD: `SteamCMD/steamapps/workshop/content/<AppID>/<ModID>/`.

---

### Шаг 3. Сборка модов в единую папку
Запустите **`extract.bat`** (или `python extract_mods.py`).

1. Скрипт найдет папку с игрой (например, `108600` для Project Zomboid).
2. Зайдет в каждый скачанный воркшоп-мод, найдет внутри папку `mods` и скопирует все моды в одну общую директорию:
   ```text
   SteamCMD/steamapps/workshop/content/108600/mods/
   ```
3. В конце предложит открыть получившуюся папку в Проводнике Windows (`y/n`).
4. **Готово!** Копируйте содержимое этой папки в папку `mods` вашей игры (например, в `C:\Users\<Имя>\Zomboid\mods`).

## ⚙️ Настройки и авторизация

По умолчанию в `download_mods.py` используется анонимный вход:
```python
STEAM_USER = "anonymous"
```
* **Project Zomboid (108600)** и ряд других игр позволяют скачивать моды анонимно без привязки к аккаунту.
* Если игра требует купленную лицензию в Steam для доступа к мастерской (например, *RimWorld*, *Arma 3*), укажите ваш логин Steam в переменной `STEAM_USER = "ваш_логин"`. При первом запуске SteamCMD запросит пароль и код Steam Guard.

---

## 🛡️ Информация о репозитории (.gitignore)

При первом запуске `SteamCMD\steamcmd.exe` автоматически скачивает все свои служебные файлы (библиотеки dll, движок, логи, манифесты). 

Благодаря файлу `.gitignore`:
- В Git отслеживается **только сам `SteamCMD/steamcmd.exe`**.
- Все скачиваемые гигабайты модов, временные кэши, архивы и логи **не попадают** в репозиторий.
- При клонировании репозитория на другой компьютер достаточно просто запустить `run.bat` — SteamCMD сам восстановит свои компоненты при первом старте.
